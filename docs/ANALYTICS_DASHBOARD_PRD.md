## 一、产品概述

### 1.1 产品定位
数据仪表盘是短剧翻译平台的核心数据分析模块，为运营决策、译员管理和财务结算提供全方位的数据支撑。通过可视化图表和详细数据列表，帮助管理者实时掌握平台运营状况，优化资源配置，提升翻译质量和投放效果。

### 1.2 目标用户
- **运营管理者**: 监控整体运营数据，制定运营策略
- **项目经理**: 跟踪短剧进度，协调资源分配
- **财务人员**: 核算翻译成本，进行财务结算
- **译员管理者**: 评估译员绩效，优化译员配置
- **投放运营**: 分析投放效果，优化ROI

### 1.3 核心价值
- **数据驱动决策**: 通过实时数据分析，支持科学决策
- **效率提升**: 快速定位问题，优化工作流程
- **成本控制**: 精准核算成本，提高资源利用率
- **质量保障**: 监控翻译质量，持续改进服务

| 短剧ID | String | 短剧唯一标识 | D001-EN |
| 短剧名称 | String | 短剧标题 | 霸道总裁爱上我 |
| 语种 | String | 翻译目标语种 | 英语 |
| 集数 | Number | 短剧总集数 | 80集 |
| 当前环节 | Enum | AI翻译/人工翻译/审核质检/成片压制/已完成 | 成片压制 |
| 进度 | Number | 完成百分比 | 85% |

| 质检 | String | 负责质检的人员姓名 | 小王 |

- **译员/质检筛选**: 下拉选择框，支持搜索，显示所有译员和质检人员
- **环节筛选**: 下拉选择框（全部/AI翻译/人工翻译/审核质检/成片压制/已完成）
- **时间范围**: 日期范围选择器，筛选开始时间
- **重置按钮**: 一键清空所有筛选条件

#### 4.2.4 排序功能

#### 4.2.7 数据来源
- 组件: AnalyticsDramaProgress
- Mock数据: mockDramaProgress（30+条记录）

### 4.3 Tab 2: 任务进度

#### 4.3.1 功能描述
展示所有翻译任务的详细进度，按任务环节维度统计，支持查看任务轮次（审核驳回重做）。

#### 4.3.2 数据字段
| 字段名 | 字段类型 | 说明 | 示例 |
|--------|---------|------|------|
| 任务ID | String | 自动生成的任务唯一标识 | D001-EN-FY-R1 |
| 短剧名称 | String | 短剧标题 | 霸道总裁爱上我 |
| 语种 | String | 翻译目标语种 | 英语 |
| 环节 | Enum | AI翻译/人工翻译/审核质检/成片压制 | 人工翻译 |
| 轮次 | Number | 任务轮次（审核驳回会产生新轮次） | 1 |
| 进度 | Number | 完成百分比 | 100% |
| 译员 | String | 负责人员姓名 | 张三 |
| 质检 | String/Array | 质检人员姓名（可能多人） | ["小王", "小李"] |
| 开始时间 | DateTime | 任务开始时间 | 2024-01-29 09:00 |
| 结束时间 | DateTime | 任务结束时间（未完成为null） | 2024-02-01 17:30 |

#### 4.3.3 任务ID生成规则
格式: `{短剧ID}-{语种代码}-{环节代码}-R{轮次}`

环节代码映射:
- AI提取: TQ
- 视频擦除: CS
- AI翻译: FY
- 人工翻译: FY
- 审核质检: ZJ
- 成片压制: YZ

示例:
- D001-EN-FY-R1: 霸道总裁爱上我-英语-翻译-第1轮
- D002-KO-ZJ-R2: 穿越之王妃驾到-韩语-质检-第2轮（审核驳回后的第二轮）

#### 4.3.4 任务轮次规则
1. **只有人工翻译和审核质检有轮次概念**，其他环节都是第1轮
2. **审核驳回会产生新轮次**:
   - 第1轮审核质检完成后，如果驳回，会产生第2轮人工翻译
   - 第2轮人工翻译完成后，会产生第2轮审核质检
   - 以此类推
3. **工作流顺序**: AI翻译 → 人工翻译 → 审核质检 → 成片压制
4. **如果某个环节存在，之前的环节也必须存在**

#### 4.3.5 筛选器
- **短剧筛选**: 下拉选择框，支持搜索
- **语种筛选**: 下拉选择框，8种语言
- **译员/质检筛选**: 下拉选择框，支持搜索
- **环节筛选**: 下拉选择框（全部/AI翻译/人工翻译/审核质检/成片压制）
- **重置按钮**: 一键清空所有筛选条件

**重要**: 环节筛选器必须严格匹配选中的环节，不能显示其他环节的任务。

#### 4.3.6 排序功能
- 支持字段: 短剧名称、语种、环节、轮次、进度、译员、质检、开始时间、结束时间
- 排序方式: 升序/降序
- 默认排序: 无

#### 4.3.7 分页功能
- 每页显示: 20条（可选10/20/50/100）
- 分页控件: 首页、上一页、页码、下一页、末页

#### 4.3.8 交互逻辑
- **点击译员/质检**: 跳转到译员绩效Tab，查看该译员详情
- **环节徽章**: 不同环节显示不同颜色
  - AI提取: 紫色
  - 视频擦除: 粉色
  - AI翻译: 靛蓝色
  - 人工翻译: 蓝色
  - 审核质检: 天蓝色
  - 成片压制: 绿色

#### 4.3.9 数据来源
- 组件: AnalyticsTaskProgress
- Mock数据: allTaskList（60+条记录，包含多轮次任务）

### 4.4 Tab 3: 译员绩效

#### 4.4.1 功能描述
展示所有译员的综合绩效数据，支持多维度筛选和排序，用于译员管理和绩效评估。

#### 4.4.2 数据字段
| 字段名 | 字段类型 | 说明 | 示例 |
|--------|---------|------|------|
| 译员姓名 | String | 译员姓名 | 王五 |
| 类型 | Enum | 翻译/审校 | 翻译 |
| 综合评分 | Number | 质量评分（0-10分） | 9.2 |
| 评级 | Enum | S级/A+级/A级/B级/C级 | S级 |
| 任务数量 | Number | 完成的任务数 | 18个 |
| 视频时长 | Number | 翻译的视频总时长（分钟） | 400分钟 |
| 有效工作时长 | Number | 实际工作时长（分钟） | 1800分钟 |
| 单价 | Number | 每分钟单价（元） | ¥45 |
| 结算金额 | Number | 总结算金额（元） | ¥81,000 |
| 修改率 | Number | 审校修改率（%） | 8.5% |
| 返修率 | Number | 译员自修率（%） | 4.2% |
| 语言 | Array | 擅长的语言 | ["英语", "日语", "韩语"] |
| 擅长剧本 | Array | 擅长的剧本类型 | ["现代剧", "都市剧"] |
| 状态 | Enum | 空闲/忙碌 | 空闲 |

#### 4.4.3 评级规则
- **S级**: 综合评分 ≥ 9.0
- **A+级**: 综合评分 8.5 - 8.9
- **A级**: 综合评分 8.0 - 8.4
- **B级**: 综合评分 7.5 - 7.9
- **C级**: 综合评分 < 7.5

#### 4.4.4 工作时长计算规则
- **视频时长**: 翻译的视频总时长（原始视频长度）
- **有效工作时长**: 实际工作时长（包含翻译、修改、审核等）
- **效率比**: 有效工作时长 / 视频时长 ≈ 4.5（即1分钟视频需要4.5分钟工作时长）

#### 4.4.5 筛选器
- **语种筛选**: 下拉选择框，8种语言
- **译员筛选**: 下拉选择框，支持搜索
- **评级筛选**: 下拉选择框（全部/S级/A+级/A级/B级/C级）
- **擅长类型筛选**: 下拉选择框（全部/现代剧/都市剧/古装剧/武侠剧/悬疑剧/推理剧/宫廷剧/爱情剧/青春剧）
- **译员类型筛选**: 下拉选择框（全部/翻译/审校）
- **状态筛选**: 下拉选择框（全部/空闲/忙碌）
- **重置按钮**: 一键清空所有筛选条件

#### 4.4.6 排序功能
- 支持字段: 综合评分、任务数量、视频时长、有效工作时长、单价、结算金额、修改率、返修率
- 排序方式: 升序/降序
- 默认排序: 按综合评分降序

#### 4.4.7 分页功能
- 每页显示: 20条（可选10/20/50/100）
- 分页控件: 首页、上一页、页码、下一页、末页

#### 4.4.8 合计行
显示当前页的合计数据:
- 任务数量合计
- 视频时长合计
- 有效工作时长合计

## 八、数据统计规则

### 8.1 概览卡片统计规则

#### 8.1.1 总短剧数
- 统计范围: 所有短剧
- 计算方式: COUNT(dramas)
- 完成率: 已完成短剧数 / 总短剧数

#### 8.1.2 进行中短剧数
- 统计范围: 状态为"翻译中"、"质检中"、"成片压制中"的短剧
- 计算方式: COUNT(dramas WHERE status IN ['翻译中', '质检中', '成片压制中'])
- 细分统计: 按当前环节分组统计

#### 8.1.3 活跃译员数
- 统计范围: 当前有任务的译员
- 计算方式: COUNT(DISTINCT translators)
- 数据来源: mockTranslators.length

#### 8.1.4 短剧平均完成时长
- 统计范围: 已完成的短剧
- 计算方式: AVG(endDate - startDate)
- 单位: 天

#### 8.1.5 平均修改率
- 统计范围: 所有译员
- 计算方式: AVG(modificationRate)
- 细分: 审校修改率、译员自修率

#### 8.1.6 本月翻译成本
- 统计范围: 本月所有译员的成本
- 计算方式: SUM(cost)
- 数据来源: translatorStats.totalCost

#### 8.1.7 高评级译员占比
- 统计范围: 所有译员
- 计算方式: COUNT(translators WHERE rating IN ['S', 'A+']) / COUNT(translators)
- 数据来源: translatorStats.highRatingPercentage

#### 8.1.8 投放ROI Top1
- 统计范围: 所有投放数据
- 计算方式: MAX(roi)
- 显示: 最高ROI的短剧名称和语种

### 8.2 图表统计规则

#### 8.2.1 短剧完成效率趋势
- X轴: 时间（按日/周/月聚合）
- Y轴: 完成数量
- 数据来源: 已完成短剧的完成时间

#### 8.2.2 短剧状态分布
- 数据维度: 各状态的短剧数量
- 计算方式: GROUP BY status, COUNT(*)

#### 8.2.3 TOP译员双维度对比
- 排序: 按完成任务数降序
- TOP数量: 10位
- 数据维度: 完成任务数、质量评分

#### 8.2.4 译员效率比监控
- X轴: 翻译效率（任务完成速度）
- Y轴: 质量评分
- 数据点: 每个译员

#### 8.2.5 语种分布
- 数据维度: 各语种的短剧数量
- 数据来源: languageDistributionData

#### 8.2.6 译员评分分布
- 数据维度: 各评级的译员数量
- 计算方式: GROUP BY rating, COUNT(*)

| 语种 | String | 翻译语种 | 英语（徽章） |
| 视频时长 | Number | 视频原始时长 | 1小时20分钟 |
| 有效工作时长 | Number | 实际工作时长 | 6小时30分钟 |
| 完播率 | Number | 视频完播率 | 85.2% |
| 修改率 | Number | 审校修改率 | 8.5% |
| 返修率 | Number | 译员自修率 | 4.2% |
| 结算金额 | Number | 任务结算金额 | ¥3,600（绿色） |
| 开始时间 | DateTime | 任务开始时间 | 2026-01-15 09:00 |
| 完成时间 | DateTime | 任务完成时间 | 2026-01-18 16:30 |
| 状态 | Enum | 任务状态 | 已结算（徽章） |

#### 10.6.3 状态徽章颜色
- **进行中**: 蓝色 `bg-blue-100 text-blue-700 border-blue-200`
- **待审核**: 橙色 `bg-orange-100 text-orange-700 border-orange-200`
- **待结算**: 紫色 `bg-purple-100 text-purple-700 border-purple-200`
- **已结算**: 绿色 `bg-green-100 text-green-700 border-green-200`

#### 10.6.4 数据高亮规则
- **完播率**: 
  - ≥80%: 绿色字体（优秀）
  - <60%: 红色字体（需改进）
- **修改率**: 
  - <10%: 绿色字体（质量好）
- **返修率**: 
  - <5%: 绿色字体（质量好）
  - >8%: 红色字体（需改进）

#### 10.6.5 排序功能
- **支持排序字段**: 视频时长、有效工作时长、完播率、修改率、返修率、结算金额、开始时间、完成时间
- **排序方式**: 升序/降序切换
- **默认排序**: 按完成时间降序
- **排序图标**: ↑升序 / ↓降序 / ↕未排序

#### 10.6.6 分页功能
- **每页显示**: 20条（可选10/20/50/100）
- **分页控件**: 首页、上一页、页码、下一页、末页
- **显示信息**: "共X条，第Y页/共Z页"

#### 10.6.7 合计行
显示当前筛选结果的合计数据：
- **任务数合计**: 合计 (XX个任务)
- **视频时长合计**: X小时X分钟
- **工作时长合计**: X小时X分钟
- **平均完播率**: XX.X%
- **平均修改率**: XX.X%
- **平均返修率**: XX.X%
- **结算金额合计**: ¥XX,XXX（绿色大字体）

### 10.7 月份选择功能

#### 10.7.1 月份选项
- **全部任务**: 显示译员的所有历史任务
- **按月筛选**: 2026年01月、2025年12月、2025年11月...
- **数据来源**: 根据任务的完成时间自动生成月份选项

#### 10.7.2 月份切换逻辑
- 选择月份后，月度汇总卡片和任务列表都会更新
- 筛选条件会保持，但分页会重置到第1页
- 合计行数据会重新计算

### 10.8 操作功能

#### 10.8.1 下载清单
- **功能**: 下载选中月份的任务清单
- **格式**: Excel文件
- **文件名**: `{译员姓名}_{月份}_任务清单.xlsx`
- **内容**: 包含所有任务字段和合计数据

#### 10.8.2 按月结算
- **触发条件**: 必须选择具体月份（不能是"全部任务"）
- **功能**: 对选中月份的待结算任务进行批量结算
- **确认机制**: 弹出确认对话框，显示结算金额和任务数量
- **状态更新**: 结算后任务状态从"待结算"变为"已结算"

### 10.9 数据生成规则

#### 10.9.1 任务数据分布
- **2026年01月**: 约15%任务（进行中、待审核、待结算）
- **2025年12月**: 约25%任务（待结算）
- **2025年11月**: 约20%任务（已结算）
- **2025年10月**: 约20%任务（已结算）
- **2025年09月**: 约15%任务（已结算）
- **2025年08月**: 约5%任务（已结算）

#### 10.9.2 任务ID生成规则
格式: `T{译员姓名}-{序号}`
- 示例: `T王五-001`、`T张三-015`

#### 10.9.3 数据稳定性
- 使用固定种子的随机数生成器
- 基于译员姓名生成种子，确保数据稳定
- 每次访问同一译员详情页，数据保持一致
